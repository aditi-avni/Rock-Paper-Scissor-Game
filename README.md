# Rock Paper Scissor Game

A simple and interactive Rock Paper Scissor game built using HTML, CSS, and JavaScript.

This project was created to practice JavaScript concepts like DOM manipulation, event handling, conditional logic, and dynamic UI updates.

---

## Features

- Interactive gameplay
- Random computer choice generation
- Live score tracking
- Dynamic result messages
- Color-changing result display
- Clean and responsive UI

---

## Tech Stack

- HTML
- CSS
- JavaScript

---

## Concepts Practiced

- DOM Manipulation
- Event Listeners
- Functions
- Conditional Statements
- Arrays and Randomization
- Dynamic Styling with JavaScript

---

## How to Run

1. Download or clone the repository
2. Open `index.html` in your browser
3. Play the game
